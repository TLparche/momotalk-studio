# MomoTalk Studio

A MomoTalk-style chat editor built with Vue 3 + Vite.

## Inspiration

This project is inspired by:

- https://github.com/U1805/momotalk

## Features

- MomoTalk-style chat UI
- Character selection and custom character management
- Markdown + LaTeX rendering in chat blocks
- Per-block text styling (font family, size, weight, alignment, color)
- Adjustable chat background and image block size
- JSON import/export for chat data

## Getting Started

```bash
npm install
npm run dev
```

Open the local URL shown in the terminal (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Routes

- `/chat` - Main chat editor
- `/characters` - Character management
- `/help` - Help page
